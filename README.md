# Fallen Forest

Unity 6 Android horror game project.

This repository is being prepared for the final production pass and Android APK build pipeline.

Core design:
- dense first-person night forest;
- floating joystick on the left half of the screen;
- camera look on the right half;
- 10 randomized document folders;
- Locust stalking/peek AI and final chase;
- one-time rare Boiled One encounter;
- supplied two Locust screamer sounds = two distinct jumpscares;
- supplied Boiled One video event;
- final escape through any forest boundary after document #10.
